Comment ça marche ?

1. Dans Google Sheets, cliquer sur « Partager », ajouter l’adresse ci-dessous avec le rôle « Lecteur » (sans notification si cette option est proposée). 2. Copier son URL ici. 3. Choisir l’onglet entrainement. 4. Tester et activer. 5. Les prescriptions se synchronisent ; les indicateurs sportifs sont récupérés depuis le premier onglet du fichier.

Protection de mes données

PaceFlow & mon coach

Mon coach peut consulter les informations nécessaires à mon suivi sportif : profil, entraînements, retours, performances et, si je connecte Garmin, les données sportives synchronisées.

Ces informations sont utilisées pour organiser et adapter mon entraînement.

Mes droits

Je peux demander l’accès, la rectification, l’export ou l’effacement de mes données. Je peux retirer un consentement lorsqu’un traitement repose sur celui-ci. Certaines informations peuvent devoir être conservées si une obligation ou une autre base légale l’exige.
