# Luis Transformation v9.3 — Photos & imports Course

- Prévisualisation obligatoire avant sauvegarde d’une photo.
- Photos compressées en JPEG et stockées comme Data URL dans IndexedDB pour une meilleure compatibilité Safari/iPhone.
- Affichage explicite lorsqu’une ancienne photo n’est plus disponible sur l’appareil.
- Export global compatible avec les anciennes photos Blob et les nouvelles photos Data URL.
- Sélection Garmin sans filtre iOS bloquant : GPX, TCX et CSV sont visibles dans Fichiers.
- Parcours Course en deux étapes : choisir le fichier, voir son nom/format/taille, puis confirmer l’analyse et l’import.
- Messages d’erreur et de réussite visibles.
